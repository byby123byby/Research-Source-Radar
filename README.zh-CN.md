# Research Source Radar

**用它找到和你的项目真正匹配的论文、开源项目、数据集、方法和其他资料。**

[快速开始](#快速开始) · [核心能力](#核心能力) · [输出内容](#输出内容) · [迁移完整性](#来源到目标的迁移完整性) · [安装](#安装) · [English](README.md)

</div>

Research Source Radar 是用来帮你找和项目真正匹配的论文、开源项目、数据集和方法的 Skill。它会先理解项目要解决的问题，再找直接相关、机制相近或可以借鉴的来源，而不是按几个关键词堆出一串链接。

## 快速开始

普通使用不需要填写结构化表格，直接说：

> 用 Research Source Radar 帮我看看和这个项目相关的论文、开源项目和资料，重点找真正能推动项目的来源。我的项目是……

如果你已经有觉得相关的来源，也可以一起贴上 1–n 个：

> 这些论文/项目是我觉得相关的。请先确认真实身份，比较它们的机制、差异和适用边界，再根据共同特点寻找新的来源。

Skill 会把这些来源作为当前任务的可见偏好假设，和真正新发现的来源分开标记。单个例子只形成暂定假设，多个例子出现一致机制时，当前任务的检索与排序会更有针对性。

## 核心能力

- **问题直连**：寻找直接解决目标问题的论文、项目、数据集、标准、官方文档和方法。
- **机制邻居**：沿着状态表示、更新规则、训练方法、测量指标、数据流程或验证方式寻找不一定同名的来源。
- **跨学科迁移**：连接计算机、生命科学、健康、社会科学、金融量化、法律政策、人文、艺术、设计、教育和其他研究领域。
- **热门与近期发现**：把 GitHub 活跃度、社区关注、论文新近发布和技术报道作为补充发现入口，同时单独说明热度时间与证据，不替代问题直连检索。
- **长尾恢复**：寻找不热门但机制清楚、验证充分或可能推动项目的来源。
- **真实来源核验**：优先定位论文原文、官方项目页、规范 GitHub 仓库、数据集主页、标准文本或其他一手来源。
- **可行动排序**：区分直接可用、需要适配、只能借鉴机制、只作参考和待核实，不把“相关”平均当成“值得深入”。

## 输出内容

通常会给出 10–20 个候选，默认约 12 个。每张候选卡都应包含：

- 来源：可直接打开的真实来源链接或稳定标识；
- 是什么：项目、论文、数据集、方法、标准或其他来源的简要说明；
- 为什么现在看：它和当前项目的具体连接；
- 项目时间范围：发布、版本、更新或关键评测的大致时间；
- 热度/时效说明：如果属于热门或近期来源，说明热度发生在什么时候；
- 机制标签：它解决了什么机制问题；
- 对目标的价值：直接可用、需要适配重实现、机制参考、轻量参考或待核实；
- 风险与限制：证据、实现、数据、平台、许可或迁移方面的风险；
- 推荐注意力：**夯 > 顶级 > 人上人 > NPC > 拉完了**。

这套注意力等级不是简单的相关性评分：

- **夯**：优先深读，并优先安排迁移或验证；
- **顶级**：高优先级深读；
- **人上人**：机制有明显价值，重点参考或适配；
- **NPC**：相关但只适合轻量参考，不建议平均深入很多；
- **拉完了**：当前任务中不值得投入。

## 来源到目标的迁移完整性

当你要求借鉴一篇论文、一个开源项目、模型、截图或技术线索时，Skill 会先建立来源能力清单，而不是只摘取几个熟悉的机制：

1. 确认来源身份和版本；
2. 阅读论文、README、实现代码、配置、评测、限制和版本记录中与目标有关的内容；
3. 列出关键机制、前提、状态变量、更新规则、验证方式、失败处理、资源/平台约束和评估结论；
4. 逐项映射到目标项目；
5. 将每一项标为直接可用、需要适配重实现、刻意不采用或尚未核实；
6. 为每个“不采用”说明原因，为每个“已迁移”指向目标设计、代码或测试；
7. 仍有未解释项目时，保留为待处理项，不提前宣布完整迁移。

这套流程同样适用于生物方法、金融因子、法学框架、人文理论、艺术工具和其他跨学科来源。

## 用户反馈与偏好

你可以直接说：

- “这个来源一般般”：只降低这个候选；
- “这批推荐一般”：记录为本轮检索失败，诊断遗漏方向后换检索路线；
- “这种机制我想多看”：增加当前任务中相似机制的探索；
- “这类我不想再推荐”：降低相似类型，但不把所有相关标签一并拉黑；
- “我觉得相关的是这几个”：贴出 1–n 个来源，让 Skill 先核验并猜测当前任务的偏好。

如果整批结果不符合预期，Skill 可以只问少量针对性问题，再根据你指出的机制、实现、数据、指标、验证或跨域迁移方向重新发现，不会把一次失败自动写成永久个人偏好。

## 安装

将本目录安装为 Codex Skill：

```text
$CODEX_HOME/skills/research-discovery-and-translation-audit/
```

原生 Agent Skills 宿主可使用内部兼容名称 `$research-discovery-and-translation-audit`；实际使用时直接说“用 Research Source Radar”即可。
